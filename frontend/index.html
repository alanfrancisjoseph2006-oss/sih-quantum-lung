Hybrid Quantum-Classical AI
for Early Lung Cancer Detection

A chest-CT decision-support platform that runs a classical deep-learning branch, a variational quantum branch, and a hybrid fusion of the two — then reports what each one concluded, how much they agree, and exactly what the underlying data does and does not support.

Architecture

Medical imaging → deep learning → quantum → fusion → explainable report

Classical Branch

Transfer-learned CNN feature extractor

An ImageNet-pretrained EfficientNet-B3 (and a DenseNet-121 baseline) is fine-tuned on the cleaned CT set and produces a 256-dimensional embedding. That embedding feeds a softmax head plus four classical comparison classifiers — Random Forest, RBF-SVM, XGBoost and logistic regression.

Quantum Branch

Variational circuit on reduced features

The embedding is scaled, reduced by PCA to 32 components, then linearly projected onto n qubits and angle-encoded as RY rotations. A shallow parameterised circuit of RY/RZ rotations with a CNOT ring is measured in the Pauli-Z basis, giving n quantum features that drive a linear read-out.

Hybrid Fusion

Four strategies, chosen on validation

Weighted averaging, a small neural fusion network, a logistic meta-classifier, and feature concatenation into XGBoost. The strategy is selected on the validation split only — the held-out test set is never used to choose anything.

Scientific Honesty

What this platform refuses to do

It does not predict cancer stage, because the dataset has no stage labels. It does not output segmentation, because the dataset has no tumour masks. And it does not claim quantum advantage — we ran the significance test, and report the result either way.
